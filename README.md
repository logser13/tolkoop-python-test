# ТОЛЬКООПТ: решение тестового задания

## Файлы решения

- `starter.py` - исправленная функция, исходный интерфейс и пример сохранены.
- `test_starter.py` - 10 автоматических тестов, включая дополнительные проверки через subTest.

Требуется Python 3.10 или новее. Внешних зависимостей нет. Проверено на Python 3.12.10.

Из каталога с файлами:

```text
python -m unittest -v
python starter.py
```

Пример возвращает `price = Decimal("4728.00")`, `decision = "APPLY"`.

## Как работает исправление

`asyncio.wait_for` ограничивает ожидание источника параметром timeout_s. Тайм-аут, исключение источника и любой status, отличный от success, возвращают текущую цену с HOLD. Отмена вызывающей задачи распространяется наружу.

Фильтрация исключает MYSHOP без учёта регистра, неизвестную доставку и доставку дольше 6 дней. При отсутствии подходящих предложений сохраняется текущая цена, даже если она ниже min_price.

Расчёт целиком использует Decimal: минимальная цена конкурента умножается на 0.985 и округляется вниз до копейки. После применения min_price проверяется абсолютное изменение относительно текущей цены: больше 30% означает REVIEW, ровно 30% означает APPLY. REVIEW возвращает рекомендованную цену, но запрещает её автоматическое применение.

Формат входа считается корректным по контракту задания. Ожидание предполагает асинхронный источник, который не блокирует цикл событий и корректно реагирует на отмену.

## Что проверяют тесты

Обычный пример; фильтрацию предложений; округление вниз; min_price; пустую и полностью отфильтрованную выдачу; partial/error; исключение источника; тайм-аут; границу 30% в обе стороны, включая влияние min_price; отмену вызывающей задачи.

Репозиторий содержит учебную функцию расчёта цены и тесты. Реальные запросы к площадкам не выполняются.
